## How it works

`main.py` copies `entry.png` to `/output/entry.png` and checks the copy's SHA-256 against the source, so the program is deterministic: every run writes the same bytes. The image itself was drawn with a Pillow script (fixed fonts, geometry and text — no randomness, no network).
